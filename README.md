## 三、怎么用这个仓库

每周实验完成后，按以下节奏归档：

1. 把本周的代码、笔记放进对应的 `WeekNN/` 目录；
2. 删掉该目录里不再需要的 `.gitkeep`（目录里有真实文件后它就没用了）；
3. 回到仓库根目录执行三条命令：

```bash
git add .                          # 把改动放进"待提交"暂存区
git commit -m "Week05: 完成 xx 实验"   # 生成一次提交快照，写明做了什么
git push                           # 推送到 GitHub 远程仓库
```

## 四、提交信息（Commit Message）约定

统一采用 `类型: 简要说明` 的格式，方便日后回溯：

| 类型 | 含义 | 示例 |
| :--- | :--- | :--- |
| `feat` | 新增功能或实验 | `feat: Week03 完成数据清洗实验` |
| `fix` | 修复错误 | `fix: 修正 Week04 循环越界` |
| `docs` | 只改文档 | `docs: 补充 Week06 实验说明` |
| `chore` | 杂项（配置、目录等） | `chore: 更新 .gitignore` |
